## What Helm is asked to SIGN

The card left three questions to the ruling. Each is answered below with a
recommendation and the measurement behind it; the SIGN adopts or amends them.

**Q1 — is `Base Dmg:` admitted at all?** Recommend **admit**. The permissive
direction adds exactly one true row: `Keg Mallet` (`Base Dmg: 9`, `Atk Delay: 30`,
ratio 0.30, 1H Blunt) gains a `Dmg`, a `Ratio`, and a place in the weapon half of
`ItemDominance`. The alternative — one deliberately unread record — leaves a
measured absence that every future census has to footnote, for no saved risk:
the record is a real weapon and the number is the page's own.

**Q2 — spelling list or pattern?** Recommend **exact spelling list, never a
pattern** — and this is now measured, not taste. The full census of `* Dmg:`
keys in the shipped catalog (11,196 records):

| key | records |
|---|--:|

| `Base Dmg` | 1 (Keg Mallet) |

**All 11 elemental/bane records also carry a plain `DMG:` line** (Greenmist,
Gnoll Slayer ×2, Gunthak Dagger/Scimitar, Staff of the Spiritcharmer, Fleeting
Memory, and the four arrow records). A pattern admitting `.* Dmg:` into the
damage slot would not merely admit unmeasured spellings — it would *overwrite
true base damage with a bonus number* on 11 named shipped records, order-decided.
Trap 66's shape, with the victims already in the file. `PairRx` already matches
all of these keys today; the exact `switch` list is the only thing keeping them
out, which is the design to extend, not replace.

**Q3 — is the count pinned?** Recommend **pin the whole census**. The test

`Ratio = 0.3`. A refresh that introduces a seventh spelling — or a second
`Base Dmg` record — reddens by count and says so, which is the card's ask.

## The change

`ItemStatsBlock.Parse` normalizes every `PairRx` key to squeezed uppercase before
the `switch`; `Base Dmg: 9` arrives as `BASE DMG` and falls through `default`.
The product change is one label: `case "DMG": case "BASE DMG": dmg = value;` (no
record carries both — measured, and the census test would say so if one arrives).
`WeaponProc.cs`'s doc prose narrating the 1,649-vs-1,648 gap is updated in the
same PR — after this lands the shipped code finds 1,649 and the narration would
be stale. `WeaponProcTests` uses floors (≥1,500 weapons, ≥1,000 NoEffect), so
Keg Mallet (no effect line) moves no existing assertion.
