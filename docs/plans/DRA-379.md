## What Helm is asked to SIGN

**Q1 — which figure, and how many tiles?** Recommend **one tile: `weeklyActive`**,
label "Playing this week", note **"opt-in installs only · a lower bound"** — the
card's own example, and the steadiest schema-1 figure (`concurrentNow` drifts every
10 minutes and would make the committed snapshot wrong within the hour;
`peakConcurrent` is a superlative; `dailyActive` is noisier). The band becomes four
tiles. The rest of the figures stay on the worker's own `/report` (DRA-380); the
note line links it — a navigation link, which the no-third-party-loads promise
explicitly leaves alone.

**Q2 — how the figure reaches the page: committed snapshot, not a live fetch.**
Recommend a new `scripts/landing-telemetry.ps1`: reads the worker's
`/metrics.json`, rewrites the telemetry keys in `site/metrics.json` **and** the
hero `.n` snapshot in `site/index.html` together (one writer of both, trap 4), and
prints what moved. Run by a human per refresh; each refresh is an ordinary
reviewed `site/**` PR. **Rejected: the page fetching the worker cross-origin.** It
would falsify the page's second spoken promise in the one place its scanner
(HTML+CSS) cannot see, put every visitor's browser on the worker at paint time,
and break the snapshot invariant the band is built on. **Rejected: a cron
auto-committing to `main`.** Pages publishes on merge, so that is an unattended
job publishing public numbers under the project's name. The staleness cost is
carried by the JSON's `asOf` and the scope sentence naming the snapshot date.
Values stay **flat top-level keys** (`weeklyActive`), so `landing.js` needs **zero
change** — the generic painter already paints any `data-metric` key.

**Q3 — the Evolved downloads tile stays OUT, with no "coming soon" tile.** Helm's
re-scope offers either; recommend out entirely. A tile with no number is a
promise-shaped tile ("no number is shown until it's actually measured" is the
standing guard, and there are no `EQBuddyEvolvedSetup.exe` assets to count — none
may be created for this). The all-versions downloads tile already answers
downloads and is unchanged here. The supersession the card names (Evolved
downloads replacing all-versions) happens on its own card once David pushes wide
and real assets exist.

**Q4 — paint now, at N = 1.** The tension, named: `docs/v2/telemetry.md` §10 says
