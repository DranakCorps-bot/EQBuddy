## §1 The amendment — first-open prompt (the only delta to TEL-001…006)

Signed TEL-001 reads: *"No first-run prompt, no nag, no dark pattern."* The
Founder's 2026-09-22 AUTHORIZE supersedes the **first clause only**: the first
app open DOES prompt, once, asking the player to help improve EQBuddy.

What survives of TEL-001, unchanged and load-bearing:

- **OFF by default, forever, until the player says yes.** The prompt's default
  action (Esc, ✕, "Not now") is decline; decline changes nothing on disk
  except a `TelemetryPromptShown` flag.
- **The "no nag" half stands.** The prompt fires ONCE per install. Decline is
  final — no re-prompt on update, ever. The Options toggle remains the only
  way back in.
- **No dark pattern.** The prompt shows the entire payload ("here is
  everything it sends" — three fields), equal visual weight on both buttons,
  and links the requirement page. Bevel writes this copy before the client
  PR exists (§2, TEL-A) — the Founder named that order.
- Opt-in mints the install id; disable destroys it; TEL-002's key-set guard
  freezes the payload. All verbatim from the signed plan.

**Reconstructed LEAVEs** (the card text carries the DRA-132 negation-relay
form, "Soft LEAVE inventing X" = *do not invent X*): do not invent Play
(Console) work; do not invent on-by-default; do not invent payload beyond
TEL-002. TEL-006's scope freeze binds — no crash reporting, no events.
