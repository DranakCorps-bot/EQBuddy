## 1. What happened, and what is actually being changed

v2.0.2: Reviewer PASS on DRA-660, the Founder's go already given ("ship it when the
review passes"), and the release still stalled — the interactive Claude Code
session's auto-mode classifier refused `release.ps1` as a production deploy and
refused writing its own allow rule. The GO existed; the EXECUTION had no seat.

**What does NOT change:**

- **The GO stays the Founder's** (consequence item 2). Nothing here lets an agent
  decide to release. What changes is the GO's FORM: a standing or conditional go
  written on the card ("ship it when the review passes") is a go, read for meaning
  per the 2026-09-30 standing rule — it does not have to be re-typed at the moment
  of release.
- **Signing stays unconditional.** `release.ps1` still throws unless every artifact
  is `Valid` and timestamped. No bypass, no `-SkipSign`, no warn-and-continue.
- **Fable's release review still precedes the go** where CLAUDE.md requires it; the
  release-review card is where the go is recorded.
- **An agent never grants itself a permission.** The allow rule is a Founder act.

## 2. Measure first (D1's first step, before anything is built)

Hypothesis, labelled as one: a Paperclip-dispatched `claude_local` seat does not run

## 3. D1 — the instrument and the procedure (one PR)

1. **`scripts/release-verify.ps1 -Tag vX.Y.Z`** — the post-release check, so "it
   shipped" is an observation rather than an exit code (trap 28, and CLAUDE.md's
   "a silent failure is not proof nothing happened"). It asserts, and prints each
   as its own row:
   - the tag exists on `origin` and points at the commit the run started from;
   - `gh release view vX.Y.Z` exists, is not a draft, and carries the expected
     assets;
   - the OneDrive file exists with a timestamp after the run began, and its
     **sha256 equals** the GitHub asset's and `dist\`'s;
   - `Get-AuthenticodeSignature` on every shipped artifact is `Valid` **and** has a
     `TimeStamperCertificate`.
   Exit non-zero on any row. **`-selftest` with prove-fail mutants** in the same
   commit (trap 34/78): a missing tag, a sha mismatch, an unsigned file and an
   untimestamped one each redden it. Wired into `check.ps1` (selftest only).
2. **`docs/ops/release-seat.md`** + a fifth row, **Release**, in
   `docs/ops/pc-change-runbook.md` (Sr Executor only). The procedure the seat runs
   on a release card:
   1. Read the card: a Founder go is present (standing or direct), Reviewer PASS,
      Fable's release review done. Missing any → stop, comment, hand back to
      Planner. Never infer a go.
   2. `git pull`; re-read `HANDOFF.md` for holds (a release hold binds).
   3. Preflight: `az account show` succeeds. If not → file/raise the Founder card
      "Founder: run `az login` (one line)" and set the release card `blocked` on it.
      This is the only human step, and it is surfaced as a card, not discovered
      three minutes into a build.
   4. `pwsh -NoProfile -File scripts/release.ps1 -Tag vX.Y.Z` (from `pwsh`, trap 27).
   5. `pwsh -NoProfile -File scripts/release-verify.ps1 -Tag vX.Y.Z`; paste output.
   6. Post the parked reporter replies listed on the card — after re-reading
      `HANDOFF.md` again, signed `— Dranak (Claude Code)`. Routine signed thread
      replies only; anything beyond that is consequence item 3 and stops.
   7. Close the card with the evidence.
   A failed `release.ps1` is never retried blind: run `release-verify.ps1` first to
   see what DID happen (tag? release? OneDrive?), paste it, and hand to Planner.
3. **The allow rule, as text the Founder pastes** — exact rule, exact file, one
   command scoped to `scripts/release.ps1 -Tag v*` and `scripts/release-verify.ps1`,
   nothing broader. D1 writes it into `release-seat.md`; D1 does NOT write it into
   any settings file.
4. **CLAUDE.md + DECISIONS.md:**
   - Consequence item 2 becomes: *"The release go. Still the Founder's, and still
     the one hard gate — but it is a decision, not a keystroke: a go may be standing
     or conditional ('ship it when the review passes') and is recorded on the
     release card. EXECUTION is the release seat's (`docs/ops/release-seat.md`);
     the Founder is never asked to run the script."*
   - The Commands block's "Releasing is `release.ps1`… Run it via `pwsh` from Bash"
     keeps the command and adds: run by the release seat on a card, verified by
     `release-verify.ps1`.
   - "Hold releases until David explicitly says ship" stays; append "(a standing go
     on the card is explicit)".
   - `DECISIONS.md` appended entry: what changed, the default it could have gone
     (keep the go per-release and typed), the Founder's quote as authority, DRA-675.
     Append-only, explicit UTF-8 (trap 60).

Done bar for D1: PR merged on Reviewer sign-off + both required checks;
